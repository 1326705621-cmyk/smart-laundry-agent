# 演示指南

## 三分钟演示流程

1. 创建个人账户并进入“我的个人空间”。
2. 打开“添加物品”并选择一张照片，在固定比例预览框中拖动、缩放并确认构图，再保存物品。
3. 一键载入演示数据，展示四类物品、固定图片框、筛选、搜索、排序和分页。
4. 切换城市，说明日期和天气会实时变化，城市偏好会保存到账户。
5. 在物品卡片勾选“今天完成”，展示状态立即变化和最近活动记录。
6. 打开智能助手，输入“帮我安排今天适合洗哪些东西”。
7. 展示天气和物品查询工具摘要，以及结合降雨、湿度和到期程度生成的计划。
8. 对 Agent 提出的完成动作点击确认，展示数据库回写闭环。
9. 创建家庭并复制家庭码，用第二个账户加入，演示成员共享同一组物品。
10. 使用普通账户说明其无法修改外观，再用首个管理员账户展示颜色与效果编辑。

## 无模型密钥演示

不填写 `OPENAI_API_KEY` 和 `OPENAI_MODEL` 即可启动。智能助手会明确显示“规则建议模式”，仍会查询天气和物品，并生成可执行计划。这是项目设计的正常降级路径，不是报错。

## 建议截图

- 首页：城市、日期、天气、待关注数量和五张物品卡。
- 添加物品：照片拖动、缩放和固定比例裁剪预览。
- 智能助手：计划、运行模式和工具调用摘要。
- 家庭管理：家庭名称、家庭码和成员空间切换。
- 外观设计：区域选择和颜色/渐变/毛玻璃控制。
