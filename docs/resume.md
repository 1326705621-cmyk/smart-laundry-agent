# AI 家庭洗晒助手 / Smart Laundry Agent

## 简历项目栏版本（当前已验证）

**项目定位：** 面向家庭场景的 AI 洗晒管理应用，将物品周期、历史记录、实时天气与大模型 Tool Calling 结合，生成可执行的洗晒计划并在用户确认后形成数据闭环。

**技术栈：** Python、Streamlit、SQLite、Open-Meteo API、OpenAI Responses API、Function Calling、Pydantic、Pytest

- 设计并实现个人账户与多家庭共享空间，支持邮箱/手机号登录、PBKDF2 密码哈希、家庭码创建/加入、个人与家庭数据隔离以及家庭成员共享修改；结合物品 CRUD、洗晒历史和任务回写形成完整业务闭环。
- 基于原生 Function Calling 构建可追踪的 Agent 工作流，封装天气查询、物品状态查询和任务完成 3 个受控工具，通过参数校验、最多 5 轮调用限制及写操作二次确认，避免模型编造事实或未经授权修改数据。
- 集成 Open-Meteo 实时天气并建立统一天气模型，支持账户级常住城市记忆和移动端授权定位，根据降雨、湿度与物品到期程度生成洗晒建议；在模型密钥缺失、API 超时或返回异常时自动降级为确定性规则模式。
- 使用 SQLite 事务、唯一约束和作用域查询实现活动记录原子更新、重复提交防护及跨家庭访问隔离；使用临时数据库、固定日期和 Fake Client 编写 70 项自动化测试，覆盖 CRUD、账户家庭、城市偏好、状态边界、天气异常、Tool Calling、Agent 降级与数据回滚。

## 招聘网站项目描述

使用 Python、Streamlit 与 SQLite 构建 AI 家庭洗晒助手，支持个人账户、多家庭空间和家庭码共享，围绕家庭物品维护、周期状态、实时天气、个性化建议和任务执行形成完整闭环。项目通过 OpenAI Responses API 的原生 Tool Calling 让模型主动调用天气和物品查询工具，并对写操作设置显式确认、参数校验及最大调用轮数。外部天气或模型服务不可用时自动降级到规则建议，确保应用仍可运行。项目配套自动化测试和中文学习 Notebook，可用于本地演示与后续部署。
